📁 WALLPAPERS FOLDER

Place your background images here.

Supported formats: PNG, JPG, GIF, WEBP
Recommended size: 1920x1080 or higher
Keep file size reasonable for fast loading (under 2MB recommended)

Examples:
- matrix.jpg (Matrix-style background)
- bitcoin.jpg (Bitcoin-themed wallpaper)
- cyberpunk.jpg (Cyberpunk aesthetic)
- neon.jpg, rain.jpg

HOW TO ADD NEW WALLPAPERS:
1. Drop your image files in this folder
2. Run: ./update-manifests.sh (from project root)
3. Refresh your dashboard

Your images will appear in:
Settings > Appearance > Wallpaper dropdown

Note: An 85% opacity overlay is applied to maintain text readability.
