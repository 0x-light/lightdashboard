📁 STICKERS FOLDER

Place your image files here to use as rain particles.

Supported formats: PNG, JPG, GIF, WEBP
Recommended size: 32x32px to 128x128px (square works best)

Examples:
- btc.png (Bitcoin logo)
- eth.png (Ethereum logo)  
- saylor.png (Michael Saylor's head)
- rocket.png (🚀 emoji as image)
- doge.png, pepe.png, wojak.png

HOW TO ADD NEW STICKERS:
1. Drop your image files in this folder
2. Run: ./update-manifests.sh (from project root)
3. Refresh your dashboard

Your images will appear in:
Settings > Rain Effect > Particle Style dropdown
